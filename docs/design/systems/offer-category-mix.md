# 오퍼 범주 혼합 (획득 / 모듈 / 시설)

## 목표

플레이어 오퍼에서 **신규 무기** 비중을 올리고 **무기 모듈** 비중을 낮춘다. 슬롯 강제(최소 N장)는 쓰지 않고 범주 배율만 조정한다. 베이 만석이면 신규 무기·모듈 배율을 더 낮추되, 획득 가중치는 0으로 두지 않아 교체 선택이 가끔 나오도록 한다.

## 동작

1. 후보 풀은 `_is_player_augment_available`로 필터한다.
2. 3장은 전부 `offer_weight` × 범주 배율로 비가중(가중) 추출한다. **특정 Kind 최소 장수 보장 없음.**

| Kind | 베이 여유 | 베이 만석 |
|------|-----------|-----------|
| `WEAPON_ACQUIRE` | ×1.8 | ×0.55 |
| `WEAPON_TRAIT` | ×0.45 | ×0.25 |
| `FACILITY_EFFECT` | ×1.0 | ×1.0 |

3. 리롤(포커스 1장): 같은 Kind 우선, 없으면 잔여 전체. 보이는 id 제외. Kind 안에서는 위 배율을 쓴다.

## 비범위

- 오퍼마다 획득/모듈/시설 슬롯 강제
- 적 오퍼 혼합
- 개별 카드 `offer_weight` 전면 튜닝

## AC

1. 빈 베이일 때 장기적으로 획득 카드 등장 횟수가 모듈보다 높다.
2. 베이 만석이면 획득·모듈 배율이 여유 시보다 낮다. 획득 배율은 0이 아니다.
3. 리롤은 같은 Kind를 우선한다.
4. `docs/spec/augments.md`·스모크가 위 규칙을 반영한다.
