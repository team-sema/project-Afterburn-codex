# 불필요한 백로그 카드 정리

## 목적

구현할 이유가 확정되지 않은 해결책 카드를 활성 칸반에서 제거해 실제 작업 후보가 선명하게 보이도록 한다.

## 정리 기준

- 현재 콘텐츠나 사용자 요구에서 실제 사용처가 없다.
- 현재 씬 생명주기로 이미 보장되어 별도 구현이 불필요하다.
- 필드나 API가 존재한다는 사실만으로 구현을 제안한다.

## 제거 대상

| 카드 | 이유 |
|------|------|
| `player-augment-behaviors` | 사용하는 플레이어 증강 리소스가 없고 실제 행동형 증강 요구가 확정되지 않음 |
| `wire-enemy-augment-grant` | 씬 사용처와 지급 게임 디자인이 없는 미사용 API 연결 제안 |
| `clear-augments-on-run` | 레지스트리가 Gameplay 씬에 귀속되고 새 인스턴스에서 초기화됨 |

## 예외 조건

- 코드의 미사용 필드·API는 이번 작업에서 삭제하지 않는다.
- `docs/spec/gaps.md`는 현재 코드 사실을 기록하므로 이번 카드 정리에서 제거하지 않는다.
- 실제 콘텐츠 요구가 생기면 구체적인 AC를 가진 새 feature 카드로 다시 등록할 수 있다.
