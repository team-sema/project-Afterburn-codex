# 불필요한 백로그 카드 정리 — Codex 활용 기록

## Codex를 어디에 사용했나요?

Project Afterburn의 `ideas`·`ready` 칸반을 코드, 씬 생명주기, 기존 스펙과 대조해 실제 기능과 기술 부채를 구분하는 데 사용했다.

## 어떤 기능을 구현했나요?

현재 사용처나 구현 근거가 없는 `player-augment-behaviors`, `wire-enemy-augment-grant`, `clear-augments-on-run` 카드 세 개를 활성 칸반과 카드 문서에서 제거했다. 제거 기준과 예외는 별도 시스템 스펙과 Task로 기록했다.

## 어떤 문제를 해결했나요?

미사용 필드나 API가 존재한다는 이유만으로 구현 후보가 쌓이고, 이미 씬 생명주기로 보장되는 초기화까지 신규 작업처럼 보이던 문제를 해결했다. 실제로 진행할 가치가 있는 리팩토링과 플레이 기능이 칸반에서 더 잘 드러나게 했다.

## 사람이 직접 결정한 부분은 무엇인가요?

사람은 아이디어·구현 대기 항목을 리뷰한 뒤 리팩토링이나 정리에 해당하는 내용이 많다고 판단했고, 그중 불필요한 카드부터 별도 feature로 정리하도록 결정했다.

## 활용 과정

1. Codex가 `ideas`와 `ready` 카드 일곱 개를 추출했다.
2. 각 카드의 코드 사용처, 씬 소유권, 테스트, 스펙을 대조해 신규 기능·유효한 리팩토링·불필요한 해결책으로 분류했다.
3. 사람이 불필요한 카드부터 정리하도록 범위를 확정했다.
4. Codex가 feature 브랜치를 만들고 대상 세 카드만 제거했으며, 나머지 후보와 코드 현황 스펙은 유지했다.
5. JSON 파싱, 잔여 링크, diff 범위를 검증한 뒤 칸반을 `review`로 전환했다.
