## 2. 역할 구분


| 역할     | 이재현                            | 최민용                              |
| ------ | ------------------------------ | -------------------------------- |
| AI 활용·개발 프로세스 | 공통 워크플로를 사용한 기능 구현·테스트 | Cursor 룰·스킬, `/feature`·`/push`, 스펙·Task·칸반 연동 설계·구현 |
| 게임 기획  | 플레이어 성장, 증강 선택 경험, 무기별 전투 감각   | 적 조우 구성, 위협도 진행, 무기 장착·시설 효과 규칙  |
| 게임 개발  | 기본 플레이 흐름, 증강 선택 시스템, 개별 무기 동작 | 적·편대·인카운터 시스템, 장착·교체·시설·실드 시스템   |
| UI·비주얼 | 증강 선택 UI, 네온 비주얼 방향과 표현 기준     | STATUS HUD, 위험 예고 UI, SVG·셰이더 제작 |
| 도구·문서  | 무기·증강 테스트 환경                   | 스펙·칸반 사이트, 개발 문서 관리 |


### 이재현 — 플레이어 경험과 비주얼 방향

플레이어가 직접 조작하고 선택하는 영역의 기획·개발 담당. 기본 플레이, 증강 선택, 무기 동작 구현과 네온 비주얼 기준 수립.

### 최민용 — AI 개발 워크플로와 콘텐츠 시스템

Cursor 룰·스킬과 `/feature`·`/push` 자동화, 스펙·Task·칸반 연동 구조 설계·구현. 적 조우·장착 구조 기획과 적·인카운터·STATUS HUD 구현 담당.

---



## 3. 협업 방식

- 기능별 담당자 1인이 `feature/<slug>` 브랜치 담당
- `docs/spec/`에 구현 현황, `docs/design/`에 기능 명세, `docs/board/`에 진행 상태 기록
- 기능 담당자가 구현·완료 조건 확인, 다른 팀원이 실제 플레이로 교차 검증
- Cursor Agent 초안은 기능 담당자가 검토·반영하며, 세부 활용 방식은 제출물 4에 별도 정리
